# Project 1: SnapText OCR + Text Data Analysis
- Description: Developed an OCR-based text extraction and data analysis application as a final semester project at Reena Mehta College, Department of Data Science.
- Tech Stack: Python, OCR, Text Processing.
- Key Achievements: Implemented optical character recognition to digitize text from image inputs, followed by structured text data analysis to derive meaningful insights from unstructured data. Designed end-to-end Python pipeline covering image input, text extraction, preprocessing, and analytical reporting.
